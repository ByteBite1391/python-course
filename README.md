## ✨ معرفی

این پروژه یک وب‌سایت آموزشی کامل برای یادگیری زبان برنامه‌نویسی پایتون (از سطح مقدماتی تا متوسط) است. ویژگی منحصربه‌فرد آن **دو رابط کاربری کاملاً متفاوت** برای **مدرّس** و **دانش‌آموز (خودآموز)** می‌باشد که تجربه‌ی تدریس در کلاس و یادگیری شخصی را بهینه می‌کند.

کل پروژه در **یک فایل HTML** نوشته شده و بدون نیاز به Backend یا نصب نرم‌افزار خاصی، فقط با یک مرورگر قابل اجراست.

🌐 **[مشاهده نسخه آنلاین](https://bytebite1391.github.io/python-course/)**

---

## 🎯 ویژگی‌های کلیدی

- 📚 **۱۹ فصل آموزشی کامل** – از «پایتون چیست؟» تا برنامه‌نویسی شی‌گرا و پروژه‌های عملی.
- 🎓 **حالت مدرّس (Teacher Mode):**
  - محتوای هر درس در قالب **۱۲ اسلاید آموزشی** (اطلاعات جلسه، معرفی مفهوم، مثال کد، توضیح خط‌به‌خط، سؤال کلاسی، تمرین، نکات مدرّس و ...)
  - ابزارهای تدریس: نمایش تمام‌صفحه، مودال بزرگ برای ویدئو پروژکتور، مخفی‌سازی پاسخ‌ها
  - قابلیت حرکت بین اسلایدها با کلیک یا کلیدهای جهت‌دار صفحه‌کلید
- 🧑‍💻 **حالت خودآموز (Self-Learning Mode):**
  - توضیحات ساده و روان، مثال کد، توضیح خط‌به‌خط
  - تمرین + پاسخ مخفی
  - **آزمون چهارگزینه‌ای** با بازخورد آنی و ذخیره نمره
  - دکمه «درس را کامل کردم» برای ثبت پیشرفت
- 💾 **ذخیره‌سازی پیشرفت** در `LocalStorage` مرورگر:
  - درصد پیشرفت کلی و هر فصل
  - درس‌های تکمیل‌شده
  - نمرات آزمون‌ها
  - آخرین درس مشاهده‌شده
- 🔍 **جستجوی قدرتمند** در تمام محتوای دوره (عناوین، توضیحات، کدها، سؤالات آزمون‌ها)
- 🌓 **حالت تاریک/روشن** (Dark/Light Mode)
- 📱 **کاملاً واکنش‌گرا** (موبایل، تبلت، دسکتاپ)
- 🎨 طراحی مدرن و راست‌چین (RTL) با فونت وزیرمتن (Vazirmatn)
- 📋 دکمه کپی کد در تمام بلوک‌های کد

---

## 🚀 اجرای پروژه

1. **دانلود** فایل `index.html` (همین یک فایل کافیست).
2. با **هر مرورگر مدرنی** (Chrome، Firefox، Edge) فایل را باز کن.
3. تمام! سایت بلافاصله در دسترس خواهد بود.

> ⚠️ **توجه:** فونت وزیرمتن از طریق CDN بارگذاری می‌شود، بنابراین برای نمایش صحیح نیاز به اتصال اینترنت دارید. در صورت آفلاین بودن، فونت پیش‌فرض سیستم (Tahoma) جایگزین می‌شود.

---

## 🛠️ تکنولوژی‌ها

- **HTML5** – ساختار صفحات
- **CSS3** (Custom Properties, Flexbox, Grid, Animations) – طراحی کاملاً سفارشی بدون فریم‌ورک
- **JavaScript (Vanilla)** – منطق برنامه، مدیریت حالت‌ها، سیستم پیشرفت، جستجو و...
- **LocalStorage API** – ذخیره‌سازی اطلاعات کاربر

همه چیز در یک فایل `index.html` تجمیع شده است. خبری از Node.js، React یا پایگاه داده نیست.

## 🧑‍🏫 نحوه گسترش محتوا

برای اضافه کردن درس جدید کافیست یک آبجکت با ساختار زیر به آرایه `courseData.chapters` در بخش `<script>` اضافه کنی:

```js
{
  id: '20-1',
  title: 'عنوان درس جدید',
  duration: '۲۰ دقیقه',
  level: 'متوسط',
  prereq: 'فصل ۱۹',
  objectives: ['هدف ۱', 'هدف ۲'],
  content: {
    intro: '...',
    simpleExplain: '...',
    codeExample: '...',
    quiz: [ ... ]
  }
}
```
